# Wintent Clothing Store Plugin

AI 驱动的服装店经营决策助手插件。

## 功能特性

- 📦 **智能库存管理** - 商品状态自动识别，快捷操作
- 🤖 **AI 决策中心** - 智能建议生成，主动推送
- 👥 **客户运营** - 个性化话术生成，精准营销
- 📊 **数据分析** - 经营概览，趋势可视化
- 🔄 **数据导入** - 支持商陆花/笑铺日记数据导入

## 安装

参考 NocoBase 插件安装文档。

## 开发

```bash
# 安装依赖
yarn install

# 启动开发环境
yarn dev

# 构建
yarn build
```
