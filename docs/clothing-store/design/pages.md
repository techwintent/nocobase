## 页面详情

### 1. AI中心（首页，默认进入）

- **功能定位**: 经营决策大脑，主动推送智能建议
- **核心区块**: 
  - 经营概览仪表板
  - AI 智能建议卡片（4类建议）
  - 快速数据导入入口
  - 系统设置入口

### 2. 库存模块

#### 2.1 商品列表
- **功能定位**: 商品库存一览，快速操作入口
- **核心区块**: 
  - 商品卡片（显示库存状态、价格、图片）
  - 操作按钮（一键促销、补货、推荐）
  - 筛选器（断码、低库存、滞销）

#### 2.2 运营活动策划
- **功能定位**: 策划营销活动，筛选目标客户
- **核心区块**: 
  - 活动类型选择器
  - 商品筛选条件设置
  - 客户匹配条件设置
  - 预览匹配结果
  - 一键执行（跳转客户模块）

#### 2.3 补货详情
- **功能定位**: 智能补货建议，搭配进货推荐
- **核心区块**: 
  - 当前库存 vs 建议库存对比
  - AI 搭配进货推荐（基于连带率分析）
  - 进货单生成和编辑
  - 预期收益预测

### 3. 客户模块

#### 3.1 客户列表
- **功能定位**: 客户档案管理，快速查找
- **核心区块**: 
  - 客户搜索和筛选
  - 客户卡片（头像、基本信息、消费统计）
  - 快速操作（查看详情、发消息）

#### 3.2 运营活动执行
- **功能定位**: 执行来自库存/AI的营销活动
- **核心区块**: 
  - 匹配客户列表（已筛选）
  - 客户卡片 + 个性化话术
  - 一键复制话术功能
  - 执行状态管理

#### 3.3 客户详情
- **功能定位**: 深度客户分析，个性化服务
- **核心区块**: 
  - 客户档案（尺码、风格、消费力等）
  - 购买历史和趋势分析
  - AI 推荐商品（基于历史偏好）
  - 个性化沟通话术

## 交互流程设计

### 1. 从库存到客户的典型流程

```
库存商品卡片 → [一键促销] → 自动跳转客户模块 
→ 显示匹配客户（已筛选断码尺码）→ 复制个性化话术 → 联系客户
```

### 2. 从AI建议的联动流程

#### 促销类建议
```
AI建议"断码促销" → 点击 → 客户模块（已匹配客户+话术）→ 执行推广
```

#### 补货类建议
```
AI建议"库存不足" → 点击 → 库存模块（补货详情+搭配推荐）→ 生成进货单
```

#### 回访类建议
```
AI建议"客户沉睡" → 点击 → 客户模块（沉睡客户列表+回访话术）→ 批量回访
```

### 3. 数据导入流程

```
AI中心 → 数据导入 → 选择数据源（商陆花/笑铺日记） 
→ 上传文件 → 字段映射确认 → 数据清洗预览 → 导入完成
```

## 界面特点

### 1. 底部导航设计
- **3栏布局**: 库存（商品管理）、AI中心（决策大脑）、客户（营销执行）
- **模块联动**: AI建议可一键跳转到对应模块的具体页面
- **默认首页**: AI中心作为入口，突出智能决策功能

### 2. 卡片化设计
- **商品卡片**: 图片 + 库存状态 + 快速操作
- **客户卡片**: 头像 + 基本信息 + 个性化话术
- **建议卡片**: AI建议 + 置信度 + 一键执行

### 3. 一步到位操作
- **避免多层嵌套**: 最多3层操作深度
- **智能预填充**: 基于AI分析预设参数
- **批量操作**: 支持批量执行营销活动

## 技术实现要点

### 1. 模块化架构
- 每个底部导航对应独立的页面模块
- 模块间通过路由参数传递联动数据
- 支持深度链接直达具体功能页面

### 2. 数据联动机制
- AI建议携带目标数据ID，跳转时自动筛选
- 库存操作生成的活动自动传递到客户模块
- 客户操作结果反馈给AI引擎优化建议

### 3. 状态管理
- 全局状态管理模块间的联动数据
- 本地状态管理单模块内的交互状态
- 持久化存储用户偏好和操作历史
