# AI 差异化价值分析

## 核心定位

> **商陆花是「记账本」，Wintent 是「军师」**

商陆花/笑铺日记：记录数据、展示统计
Wintent：分析数据 → 生成洞察 → 帮你执行

## 技术实现差异

| 维度 | 商陆花 | Wintent |
|------|--------|---------|
| **分析方式** | 固定规则（阈值触发） | AI 模型 + 规则混合 |
| **推荐逻辑** | 静态关联（人工设置） | 动态计算（历史数据 + 趋势） |
| **个性化** | 无 | 基于客户画像定制 |
| **执行闭环** | 无（只展示信息） | 有（生成话术、进货单等） |
| **外部数据** | 无 | 小红书/抖音趋势（规划中） |

## 一句话总结

| 产品 | 定位 | 价值 |
|------|------|------|
| 商陆花 | 记账本 | 帮你记录，你自己想办法 |
| Wintent | 军师 | 帮你分析，告诉你怎么做，帮你执行 |
