## 核心需求概览

### 功能需求

1. **低门槛数据录入** - 快速录入核心信息
2. **智能搭配推荐** - 进货/销售/补货场景的搭配推荐
3. **智能进货建议** - 基于销售趋势的进货建议
4. **移动端3栏导航界面** - 库存/AI中心/客户
5. **客户复购分析** - 沉睡客户识别与回访时机预测
6. **基础数据管理** - 商品/库存/客户/销售管理
7. **数据可视化仪表盘** - 关键经营数据展示
8. **AI 引擎扩展性** - 插件化架构
9. **系统性能与可靠性** - 快速响应与数据安全
10. **数据导入功能** - Excel/CSV 批量导入
11. **数据同步管理** - 定期同步现有系统数据
12. **数据质量监控** - 数据完整性与一致性检查
13. **运营活动管理** - 促销/推荐/清仓活动管理
14. **话术生成** - 个性化推荐话术
15. **经营概览可视化** - 商品和客户数据可视化
16-18. **待定需求** - 小红书搭配搜索、NFC引流、截图识别
19. **AI 建议触发机制** - 定时和数据变更触发

### 非功能需求

- **性能需求** - 响应时间 < 2秒，AI 分析 < 5秒
- **安全需求** - 本地存储，数据加密
- **可用性需求** - 系统可用性 > 99.5%
- **兼容性需求** - 支持主流手机浏览器

## 用户调研亮点

基于南瓜（种子用户）的深度调研：

- **痛点1**: 数据录入难（实体店节奏快）
- **痛点2**: 组货搭配难（进货时不知道怎么搭配）
- **痛点3**: 功能繁琐（现有软件功能多但复杂）
- **痛点4**: 决策靠感觉（有数据但不会分析）

## 设计原则

1. **主动推送** > 被动查询
2. **一步到位** > 多步操作
3. **自然语言** > 专业术语
4. **渐进式复杂度** - 新手看建议，高级用户可深入

## 验收标准

- 数据导入成功率 > 95%
- AI 建议采纳率 > 60%
- 用户独立完成核心操作（无需培训）
- 南瓜愿意付费使用
