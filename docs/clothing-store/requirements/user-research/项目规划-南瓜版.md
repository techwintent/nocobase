# 南瓜服装店 - 项目规划

## 定位调整

**原定位**：服装店进销存管理系统
**新定位**：**AI 驱动的服装店经营决策助手**

> 不是又一个进销存，而是告诉你「接下来该怎么做」

---

### Phase 1: 基础数据层（已完成设计）
打好数据底座，让 AI 有数据可分析

- ✅ 商品管理
- ✅ 库存管理
- ✅ 客户管理
- ✅ 销售开单

**状态**：数据库已建好，界面原型已设计，等待搭建

这是差异化核心，也是南瓜最需要的

| 功能 | 解决的问题 | 优先级 |
|-----|-----------|-------|
| 🤖 智能进货建议 | 进什么货靠感觉 → 靠数据 | ⭐⭐⭐ |

| 🤖 客户复购分析 | 不知道谁该回访 → 自动提醒 | ⭐⭐ |
| 🤖 滞销预警 | 压货不知道 → 及时清仓 | ⭐⭐ |

---

## 技术路径

### 数据基础（Phase 1）
```
商品数据 + 销售数据 + 客户数据
         ↓
    NocoBase 存储
```

### AI 分析（Phase 2）
```
NocoBase 数据 → 定期导出/API
         ↓
   AI 分析引擎（本地 Ollama 或云端）
         ↓
   生成建议 → 推送到仪表盘
```

### 可选方案
1. **轻量方案**：规则引擎 + 简单统计（不需要 LLM）
2. **AI 方案**：LLM 分析销售趋势、生成自然语言建议
3. **混合方案**：规则做计算，LLM 做解读和表达
