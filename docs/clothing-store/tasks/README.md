# 任务计划

本目录包含 Wintent 服装店 AI 决策助手的开发任务计划。

## 文件列表

- [`tasks.md`](tasks.md) - 完整任务计划（Phase 0-6）

## Phase 概览

### Phase 0: 数据集成准备（1天）

- 数据导入引擎设计
- 商陆花/笑铺日记导入模板创建
- 数据导入工具开发
- 导入界面搭建
- **验收**: 南瓜数据导入测试（成功率 > 95%）

### Phase 1: 核心数据层（3天）

- 数据模型设计（基于真实表头 v0.1）✅
- 生成建表脚本（NocoBase collections JSON）✅
- 执行建表并验证
- **验收**: 南瓜真实数据导入测试

### Phase 2: AI中心模块（5天）

- 经营概览设计（商品/客户统计、趋势图）
- AI建议系统（4种建议类型 + 触发机制）
- 数据导入界面集成
- **验收**: 南瓜认为 AI 建议 60%+ 有价值

### Phase 3: 库存模块（4天）

- 商品列表与状态管理
- 运营活动策划（促销/推荐/补货）
- 补货搭配推荐（连带率分析）
- **验收**: 南瓜认为比现有系统更高效

### Phase 4: 客户模块（4天）

- 客户列表管理
- 运营活动执行
- 话术生成（个性化模板）
- 客户详情页
- **验收**: 客户运营效率明显提升

### Phase 5: 南瓜深度试用（5天）

- 部署测试环境
- 真实数据录入（30+ 商品，20+ 客户）
- 使用行为观察
- 功能优化迭代
- **最终验收**: 4 个问题中至少 3 个正面回答

### Phase 6: 迭代优化（后续）

- 智能进货建议增强
- 客户复购分析优化
- LLM 集成优化

## 时间线

- **Week 1**: Phase 0 (数据集成) + Phase 1 (数据层)
- **Week 2**: Phase 2 (AI中心模块)
- **Week 3**: Phase 3 (库存模块) + Phase 4 (客户模块)
- **Week 4**: Phase 5 (南瓜深度试用)

**目标**: 4周内完成 MVP，获得南瓜认可

## 关键成功因素

1. **南瓜的参与度** - 每次验收 ≤ 30 分钟
2. **搭配推荐的准确性** - 先用规则引擎，保证基本合理性
3. **界面的简易程度** - 以南瓜的反馈为准

## 成功指标

### 用户验收指标
- ✅ 南瓜能独立完成核心操作
- ✅ 数据导入成功率 > 95%
- ✅ AI建议采纳率 > 50%
- ✅ 3个模块联动操作流畅度 > 80%
- ✅ 南瓜愿意推荐给其他店主

### 技术指标
- 批量数据导入: 1000条 < 30秒
- AI建议响应时间 < 3秒
- 模块间跳转 < 2秒

### 业务指标
- 南瓜每日活跃使用（连续 > 1周）
- AI建议准确率 > 60%
- 南瓜付费意愿确认
