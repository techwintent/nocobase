# Implementation Plan: Wintent AI 决策助手（全面更新版）

## Overview

基于新 HTML 原型 `wintent-demo.html` 的完整功能架构，全面更新实施计划。新架构采用 **移动端3栏导航 + 运营活动系统 + 话术生成** 的完整功能体系。

### 新产品架构：移动端3栏导航 + 完整功能体系

**📦 库存模块**（左栏）
- **商品列表**：商品展示 + 状态管理 + 快捷操作按钮
- **运营活动**：活动策划（促销/推荐/回访/清仓）+ 筛选条件设置
- **补货详情**：搭配推荐 + 进货单汇总 + 连带销售预估

**🤖 AI中心模块**（中栏，首页）
- **经营概览**：商品统计 + 客户统计 + 趋势图可视化
- **AI智能建议**：4种建议类型，点击联动到对应模块
- **数据导入**：商陆花/笑铺日记导入，进度展示
- **系统设置**：导入模板配置、店铺信息

**👥 客户模块**（右栏）
- **客户列表**：搜索 + 筛选 + 状态管理
- **活动执行**：运营活动客户匹配 + 个性化话术生成
- **客户详情**：基本信息 + 购买记录 + AI推荐 + 话术生成

### 核心升级
- 📱 **移动端优化**：320px-450px适配，单手操作友好
- 🎯 **运营活动系统**：完整的活动策划-执行-跟踪闭环
- 💬 **话术生成功能**：基于客户+商品的个性化话术，一键复制
- 📊 **数据可视化**：经营概览实时展示关键指标
- 🔄 **模块联动**：AI建议点击直接跳转，活动执行无缝衔接

## Critical Success Factors

### 1. 南瓜的参与度
**风险**：南瓜太忙，无法深度参与验收
**缓解**：
- 每次验收控制在 30 分钟内
- 提前约时间，不临时打扰
- 准备具体问题，不泛泛而谈

### 2. 搭配推荐的准确性
**风险**：算法推荐不符合实际经营经验
**缓解**：
- 先用规则引擎，保证基本合理性
- 与南瓜讨论具体搭配案例
- 持续调整算法权重

### 3. 界面的简易程度
**风险**：开发者觉得简单，用户觉得复杂
**缓解**：
- 以南瓜的反馈为准，不凭开发者直觉
- 每个界面都要有"一步到位"的操作路径
- 避免专业术语，用自然语言

## Notes

- **核心原则**：南瓜的反馈 > 开发者的假设
- **验收标准**：实用性 > 功能完整性
- **迭代策略**：快速验证 > 完美实现
- **差异化重点**：AI建议联动各模块 > 单一功能优化
- **架构重点**：**3栏导航模块化设计是用户体验的核心**

### 关键产品策略调整（基于3栏导航原型）

1. **架构调整**：从"功能堆砌"转向"模块联动"
   - 库存模块：商品管理 + 运营策略制定
   - AI中心模块：数据概览 + 智能建议 + 数据导入
   - 客户模块：客户管理 + 活动执行 + 话术生成

2. **交互策略**：模块间无缝跳转
   - AI中心的建议可直接跳转到库存模块执行
   - 库存模块的活动可直接跳转到客户模块执行
   - 客户模块的话术基于商品和客户信息智能生成

3. **用户体验**：渐进式学习
   - Phase 2: 让用户熟悉AI中心（首页）
   - Phase 3: 引导用户使用库存模块
   - Phase 4: 最后完善客户模块
   - 各阶段都有南瓜深度参与验收

**如果 MVP 失败（南瓜不满意）**：
- 分析失败原因：算法不准？界面复杂？功能不对？**数据导入不顺畅？模块联动不够？**
- 快速调整策略，不超过 1 周
- 必要时回到需求分析阶段

**如果 MVP 成功（南瓜满意）**：
- 立即推进 Phase 6 功能扩展
