# Wintent 服装店 AI 决策助手

> 基于 NocoBase 构建的 AI 驱动服装店经营决策助手

## 项目概述

**核心定位**：从"帮你记录"升级到"帮你决策"

**目标用户**：已使用商陆花/笑铺日记的服装店主（月销 500-1000 件）

**核心价值**：
- 🤖 进什么货？→ AI 基于销售趋势给出进货建议
- 🤖 怎么搭配？→ AI 推荐最优组合提升连带率
- 🤖 谁该回访？→ AI 识别沉睡客户最佳回访时机
- 🤖 哪些滞销？→ AI 预警库存风险并建议清仓策略

## 产品架构

### 移动端 3 栏导航

```
┌─────────────┬─────────────┬─────────────┐
│   📦 库存    │  🤖 AI中心   │   👥 客户   │
└─────────────┴─────────────┴─────────────┘
```

| 模块 | 功能 |
|------|------|
| **📦 库存** | 商品列表（状态+快捷操作）、运营活动策划、补货搭配推荐 |
| **🤖 AI中心** | 经营概览、AI智能建议、数据导入、系统设置 |
| **👥 客户** | 客户列表、运营活动执行、话术生成、客户详情 |

### 核心交互流程

```
AI建议"断码促销" → 点击 → 客户模块（已筛选客户 + 话术）
AI建议"库存不足" → 点击 → 库存模块（补货详情 + 搭配推荐）
库存商品[一键促销] → 跳转 → 客户模块（匹配客户 + 话术）
```

1. **种子数据**：已按 商陆花 表头生成
   - `scripts/seed/` - JSON 源数据（商品 10 款、库存 21 条、客户 10 人、销售单 9 单）
   - 运行 `node docs/clothing-store/scripts/generate-seed-xlsx.js` 生成 xlsx

2. **建表**：`scripts/create-tables.sh` 通过 NocoBase API 创建 14 张表

3. **导入**：使用生成的 xlsx 通过 NocoBase 数据导入功能导入

## 核心差异化

与传统进销存系统（商陆花/笑铺日记）的区别：

| 维度 | 传统进销存 | Wintent |
|-----|-----------|---------|
| **定位** | 记录工具 | 决策助手 |
| **能力** | 数据存储 | 智能分析 |
| **体验** | 功能堆砌 | 场景导向 |
| **价值** | 提升效率 | 提升决策质量 |
